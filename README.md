# AI Career Copilot

AI-powered resume analyser built with Flask. Upload a resume (PDF/DOCX) or paste text, add a target role, and get skills, missing skills, a roadmap and interview questions.

Live demo: https://ai-career-copilot-t8t3.onrender.com
(Free hosting, so the first load may take about a minute.)

Features: signup/login, resume analysis, history with delete option

Tech: Python, Flask, SQLAlchemy, TiDB (MySQL), Groq API, Render
